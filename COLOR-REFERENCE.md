# HOOKLABS Premium Silver color reference

- Primary orange: `#FF8A00`
- Main white: `#F5F6F8`
- Silver: `#D1D5DB`
- Muted gray: `#6B7280`
- Dark surface: `#1F2937`
- Main black: `#0B0B0D`
- Healthy status: `#34D399`
- Error status: `#EF4444`

Black and charcoal are dominant. Silver defines borders and reflective structure. Orange is reserved for high-value actions and highlights; semantic status colors retain their meaning.
