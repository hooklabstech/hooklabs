# HOOKLABS

HOOKLABS is an on-chain analytics and discovery platform focused on Uniswap v4 hooks and the wider Web3 ecosystem.

## Overview

- Explore hooks, pools, and activity across supported networks.
- Inspect contracts with on-chain scanning and risk signals.
- Monitor network activity and ecosystem metrics.
- Access community resources and project updates.

## Technology

Built with Next.js, TypeScript, React, and Tailwind CSS, with viem and wagmi for blockchain interactions. Neon provides database and authentication services.

## Development

```bash
pnpm install
pnpm dev
```

Some features require separately configured environment variables and external services. Keep private credentials and runtime configuration out of version control.
